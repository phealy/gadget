Gadget Module

Quick reference · Front

Complete example

# LEGO slot:0 autostart
from gadget import *

async def main():
    robot = await Gadget.setup(
        left_motor=port.A,
        right_motor=port.B,
        wheel_diameter="small",
        turn_factor=1.447,
        color_sensor=port.C,
        distance_sensor=port.D,
        force_sensor=port.F,
    )

    robot.log("Drive forward/backward at a heading.")
    await robot.drive(distance=30, angle=0)
    await robot.drive(distance=-10, angle=0)

    robot.log("Turn to an absolute global heading.")
    await robot.turn(angle=90)
    await robot.turn(angle=0, long_turn=True)

    robot.log("Use exactly one stop condition per call.")
    await robot.drive_until(colors=[GREEN, WHITE], angle=-90)
    await robot.drive_until(sensor_distance=15, angle=0)
    await robot.drive_until(pressed=True)

    robot.log("Turn right (default) or left for colors.")
    await robot.turn_until(colors=[BLACK])
    await robot.turn_until(colors=[WHITE], left_turn=True)

    robot.log("completed")

runloop.run(main())
Remember: Movement functions are asynchronous and require await.

Gadget.setup()

await Gadget.setup(
    left_motor, right_motor,
    wheel_diameter, turn_factor,
    yaw_angle=0, yaw_face=motion_sensor.TOP,
    default_drive_velocity=320, default_turn_velocity=200,
    default_acceleration=1000, default_deceleration=1000,
    default_stop_type=motor.SMART_BRAKE, steering_correction=1,
    color_sensor=None, force_sensor=None,
    distance_sensor=None, drive_pair=motor_pair.PAIR_1,
)
ParameterPurpose / accepted value
left_motorRequired. Left drive motor port. Must differ from right.
right_motorRequired. Right drive motor port. Must differ from left.
wheel_diameterRequired. "small" (5.6 cm), "large" (8.8 cm), or a positive diameter in cm.
turn_factorRequired. Positive yaw-to-motor multiplier calculated with turn_factor.py.
yaw_angleInitial global heading, −180° to 180°. Default: 0.
yaw_faceHub face pointing up. Default: motion_sensor.TOP.
default_drive_velocityDriving speed, 100–1050 °/s. Default: 320.
default_turn_velocityTurning speed, 100–1050 °/s. Default: 200.
default_accelerationAcceleration, 100–10000 °/s². Default: 1000.
default_decelerationTurn deceleration, 100–10000 °/s². Default: 1000.
default_stop_typeMotor stop behavior. Default: motor.SMART_BRAKE.
steering_correctionNonnegative gyro correction. Default: 1.
color_sensorColor sensor port. Default: None.
force_sensorForce sensor port. Default: None.
distance_sensorDistance sensor port. Default: None.
drive_pairMotor-pair identifier. Default: motor_pair.PAIR_1.

Movement Methods

Quick reference · Back

drive()

await robot.drive(
    distance, angle=None,
    long_turn=False, velocity=None,
    acceleration=None,
)

Drives a distance in centimeters while using yaw to hold a global heading. The robot first turns when it is more than 1° from the requested heading.

ParameterDescription
distanceCentimeters to drive. Negative backs up; 0 only turns.
angleHeading, −180° to 180°. Current heading if omitted.
long_turnUse the longer initial route to angle.
velocity100–1050 °/s; otherwise the drive default.
acceleration100–10000 °/s²; otherwise the default.

Examples

await robot.drive(distance=30, angle=0)
await robot.drive(distance=-15, angle=90)

drive_until()

await robot.drive_until(
    colors=None, sensor_distance=None,
    pressed=None, angle=None,
    reverse=False, long_turn=False,
    velocity=None, acceleration=None,
)

Drives until exactly one sensor condition is met. Configure the matching sensor port in Gadget.setup().

ParameterDescription
colorsOrdered color list. Copied; caller's list is unchanged.
sensor_distanceStop at or below this sensor distance, 5–100 cm.
pressedUse True to stop when force sensor is pressed.
angleHeading to hold; current heading if omitted.
reverseDrive backward when True.
long_turnUse longer initial route to the heading.
velocity100–1050 °/s; otherwise drive default.
acceleration100–10000 °/s²; otherwise default.

Examples

await robot.drive_until(colors=[GREEN, WHITE])
await robot.drive_until(sensor_distance=15, angle=0)
await robot.drive_until(pressed=True)

turn()

await robot.turn(
    angle, long_turn=False,
    velocity=None, acceleration=None,
    deceleration=None,
)

Tank-turns to an absolute global heading. By default, the robot takes the shortest route.

ParameterDescription
angleTarget global heading, −180° to 180°.
long_turnTake the longer route when True.
velocity100–1050 °/s; otherwise turn default.
acceleration100–10000 °/s²; otherwise default.
deceleration100–10000 °/s²; otherwise default.

Examples

await robot.turn(angle=90)
await robot.turn(angle=-90, velocity=250)
await robot.turn(angle=0, long_turn=True)

turn_until()

await robot.turn_until(
    colors, left_turn=False,
    velocity=None, acceleration=None,
)

Turns in place until the configured color sensor detects every color in the supplied order. The caller's list remains unchanged.

ParameterDescription
colorsOrdered list of colors to detect.
left_turnTurn left when True; right by default.
velocity100–1050 °/s; otherwise drive default.
acceleration100–10000 °/s²; otherwise default.

Examples

await robot.turn_until(colors=[BLACK])
await robot.turn_until(colors=[GREEN, WHITE], left_turn=True, velocity=200)
Color values: BLACK, MAGENTA, PURPLE, BLUE, AZURE, TURQUOISE, GREEN, YELLOW, ORANGE, RED, WHITE, UNKNOWN.
